# Bank Customer Churn Analysis

Analysis of 10,000 bank customers to find who is leaving the bank and why, built with **Power BI**.

## What's Inside

- `data/` : customer dataset (`Book12.csv`)
- `dashboard/` : Power BI file and dashboard images
- `report/` : full written report

## Key Findings

- Churn rate is **20.38%**, with about **$185.68M** in balance lost.
- **Germany** has the highest churn (32.44%), about double France and Spain.
- Customers aged **51-60** churn the most (56.21%).
- Customers with **2 products** are the most loyal (7.60% churn), while those with 3 or 4 products churn heavily.
- **Female** customers churn more than male customers (25.07% vs 16.47%).
- Complaints (2,044) are almost equal to exits (2,038), so complaint handling matters.

## Main Recommendations

- Respond faster to customer complaints.
- Focus retention efforts on Germany and customers aged 41-60.
- Re-engage inactive members.
- Review why customers with 3 or 4 products leave.
